# Online Food Delivery – Big Data Analytics Using PySpark

## Project Overview

This project is a Big Data Analytics case study based on an Online Food Delivery dataset. It demonstrates how Apache Spark and PySpark can be used to process, analyze, and derive meaningful insights from food delivery data.

The analysis focuses on understanding customer orders, popular food items, restaurant performance, sales trends, delivery times, and customer ratings using PySpark DataFrame operations, Spark SQL, and data visualization.

## Objectives

- Analyze food delivery orders using PySpark.
- Identify popular food items and restaurants.
- Calculate total sales and order values.
- Analyze delivery times and customer ratings.
- Perform data filtering, sorting, grouping, and aggregation.
- Execute analytical queries using Spark SQL.
- Present insights through data visualizations.

## Dataset Description

The project uses a sample dataset containing 15 food delivery records.

The dataset includes information related to:
- Order details
- Customer information
- Restaurant details
- Food items and quantities
- Item prices
- Delivery times
- Customer ratings
- City information

The following operations were performed as part of the case study:

5. Performing aggregate calculations.
